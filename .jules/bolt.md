## 2024-11-20 - DRF ViewSet N+1 queries with nested serializers
**Learning:** In Django Rest Framework (DRF), when a serializer like `DoctorProfileSerializer` includes nested representations or custom fields that access related models (like `UserSerializer(source='user')`, `source='specialization.name'`, or `SerializerMethodField` looping over `reviews`), doing `.all()` on the ViewSet's queryset triggers a separate SQL query for each related object for *every* item in the list response. This creates an N+1 query problem, severely degrading performance for list endpoints.
**Action:** Always explicitly use `select_related()` for foreign key and one-to-one fields (e.g., `user`, `specialization`, `hospital`) and `prefetch_related()` for reverse relationships and many-to-many fields (e.g., `reviews`) in the ViewSet `queryset` definition whenever the associated serializer exposes those related fields.
